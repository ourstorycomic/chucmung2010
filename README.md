# 🌸 Chúc Mừng 20/10 - Mỹ Tâm & Kiều Vy 💕

Dự án web 3D mây kẹo ngọt (3D Marshmallow Clouds & Candy Hearts) tự động chúc mừng Ngày Phụ nữ Việt Nam 20/10 dành riêng cho **Trần Mỹ Tâm** & **Lê Kiều Vy**.

## ✨ Tính năng nổi bật
- **3D Marshmallow & Candy Worlds**: Hiệu ứng mây kẹo 3D bồng bềnh, ly trà sữa 3D, hoa anh đào nở rộ và trái tim kẹo xoay bằng Three.js.
- **Tự động chạy hoàn toàn (Zero-Touch Movie Experience)**: 1 chạm duy nhất để bắt đầu, camera 3D tự động bay xuyên mây qua từng chặng câu chuyện.
- **Nhạc nền Music Box / Celesta**: Giai điệu du dương ngân vang được tạo tự động bằng Web Audio API.
- **Cao trào nhắm mắt nhận quà ngoài đời thật**: Tự động đếm ngược 3... 2... 1... và chuyển sang rạp chiếu bóng tối với chú khỉ nhắm mắt 🙈, sau đó bấm mở quà để nổ pháo hoa ăn mừng!

## 🚀 Hướng dẫn mở
Mở trực tiếp file `index.html` trên bất kỳ trình duyệt nào (Chrome, Edge, Safari, Cốc Cốc) hoặc deploy trực tiếp lên GitHub Pages.
